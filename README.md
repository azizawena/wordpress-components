# wordpress-components

Padrões genéricos e autorais para WordPress.

Este repositório não contém arquivos, dados ou código proprietário de clientes.

## portfolio-projects

Plugin de estudo que registra:

- Custom Post Type `portfolio_project`;
- taxonomia `project_discipline`;
- suporte a título, editor, thumbnail, excerpt e revisions;
- REST API habilitada;
- labels internacionalizáveis.

O objetivo é demonstrar organização de conteúdo estruturado, não substituir plugins maduros de produção.
