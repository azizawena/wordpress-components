# Portfolio Projects — plugin de estudo

## Instalação

1. crie a pasta `wp-content/plugins/portfolio-projects/` e copie `portfolio-projects.php` para ela;
2. ative o plugin no painel;
3. atualize os links permanentes se necessário.

## O que demonstra

- Custom Post Types;
- taxonomia;
- REST API;
- lifecycle de ativação/desativação;
- nomenclatura e prefixos;
- estrutura de conteúdo administrável.

## O que ainda não faz

- campos customizados;
- templates do front-end;
- filtros AJAX;
- permissões avançadas;
- migrations.

Esses itens entram apenas quando houver um caso de estudo claro.
